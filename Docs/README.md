# TechZone 🖥️

**Sistema de Gestión y Análisis de Productos Tecnológicos**

Proyecto final del curso **Lenguajes de Programación (100000SI68)** — Universidad Tecnológica del Perú.

---

## 📌 Descripción

TechZone es un sistema que permite gestionar productos tecnológicos, controlar stock y analizar ventas. El mismo problema fue implementado en tres lenguajes, cada uno con un paradigma diferente:

| Lenguaje | Paradigma |
|----------|-----------|
| **Scala** | Funcional |
| **SWI-Prolog** | Lógico |
| **Python** | Multiparadigma |

El objetivo es comparar cómo cada enfoque resuelve el mismo dominio: catálogo, stock, ventas e inventario.

---

## 🎯 Funcionalidades

- Registro y gestión de productos.
- Filtros por categoría, precio, nombre e identificador.
- Control de stock bajo y productos agotados.
- Cálculo del valor del inventario.
- Registro de ventas con validación de stock.
- Cálculo de ingresos totales, ticket promedio e ingresos por categoría.
- Ranking de productos más vendidos.
